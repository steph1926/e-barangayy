# Barangay Docs Pro

Improve the Admin > Document Requests page.

Add a document template system where the admin can select a document type and preview a sample printable template.

Include sample templates for:

- Barangay Certificate

- Barangay Clearance

- Certificate of Residency

- Certificate of Indigency

- Other Barangay Documents

When an admin opens a request, show the resident's submitted information and automatically place the information into the selected document template.

Add:

- Document Preview

- Edit Details

- Generate Document

- Print Document

- Download/Save as PDF UI

- Mark as Ready for Pickup

Use sample/template content only for now. The actual Barangay 902 document format will be added after it is officially provided by the barangay.

Keep the templates professional and consistent with the Barangay 902 design. Use mock data and React state only.
